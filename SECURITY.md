# Seguridad

Este servidor da acceso de solo lectura a datos de NEXO. Si encuentras una vulnerabilidad o una exposición de datos
no prevista (token aceptado sin rol, vista no marcada visible, SQL inyectable, secreto en el repositorio…):

1. **No abras una incidencia pública.** Avisa directamente a la Dirección de Tecnología de Grupo Neural.
2. Indica qué has visto y cómo reproducirlo, sin incluir datos personales ni secretos.
3. Si hay un secreto expuesto, hay que rotarlo aunque se retire del repositorio.

Capas de protección y modelo de acceso: [README.md](README.md#cómo-funciona). Reglas para cambios: [AGENTS.md](AGENTS.md).
